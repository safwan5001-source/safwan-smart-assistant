# Windows Worker

هذه حدود محرك تنفيذ Windows السحابي. لا يوجد عامل تشغيل فعلي في هذا الإصدار.

عند التنفيذ يجب:
- تسجيل العامل والتحقق من هويته قبل استقبال المهام.
- التحكم في جلسة Windows تفاعلية مرخّصة ومستقرة.
- التقاط حالة قبل وبعد كل إجراء مؤثر.
- دعم وقف التنفيذ وعدم تكرار الحفظ أو الإرسال بعد الانقطاع.
- عدم تمرير كلمات المرور أو صور الشاشة إلى سجلات عامة.
- عدم التحايل على CAPTCHA أو MFA.

لا تشغّل مهام المستخدم الحساسة قبل تفعيل المصادقة والتدقيق والموافقات.
