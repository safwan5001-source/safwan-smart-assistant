# مساعد صفوان الذكي | Safwan Smart Assistant

مساعد شخصي ذكي مستقل، يتحكم في كمبيوتر Windows سحابي ويستقبل الأوامر من الآيفون بالمحادثة الصوتية المباشرة.

> الحالة: تأسيس المشروع. لم يتم نشر النظام أو تشغيله بعد.

## الرؤية
منصة عامة لتنفيذ أعمال المستخدم على المواقع والبرامج عبر واجهاتها، بما في ذلك الملفات والبريد والمكالمات. دفترة سيناريو اختبار أول، وليست نطاق المشروع كله.

## المبادئ المعتمدة
- مستخدم واحد؛ المشروع منفصل عن أَوْج.
- واجهة ويب متجاوبة للآيفون، قابلة للإضافة للشاشة الرئيسية، بصوت مباشر قابل للمقاطعة.
- Windows سحابي للتنفيذ عبر الشاشة والماوس ولوحة المفاتيح.
- لا يُشترط API للتعامل مع دفترة؛ الأتمتة عبر الواجهة.
- عند كل مهمة يسأل المساعد: مراجعة فقط، تنفيذ، أو تنفيذ بموافقة.
- إجراءات مالية حساسة أو حذف واسع تتطلب موافقة محددة.
- سجلات تدقيق وحماية من التكرار وإيقاف فوري واستئناف آمن.
