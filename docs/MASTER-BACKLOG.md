## قواعد إدارة السجل
- الحالة: `TODO` / `IN PROGRESS` / `BLOCKED` / `IN REVIEW` / `DONE`.
- **لا يعني وجود واجهة أو كود أو مستند اكتمال القدرة.** الإغلاق يتطلب اختبارات، ومراجعة، ودمجًا ونشرًا عند الاقتضاء، وتحققًا في البيئة المستهدفة.
- كل مهمة لها دليل إنجاز: رابط PR أو اختبار أو سجل تشغيل أو توثيق معتمد، وأي عائق يُكتب صراحة.
- لا تخزن كلمات مرور أو رموز وصول أو بيانات عمل حساسة في GitHub.
- تُحدَّث الحالات بناءً على أدلة فعلية فقط. كل المهام أدناه `TODO` حتى يُفحص الواقع، ما لم يذكر خلاف ذلك.
