# المعمارية التأسيسية — إصدار 1.0

## النظام
1. **iPhone Web App / PWA:** محادثة صوتية عربية مباشرة، مقاطعة، نص، رفع الملفات، حالة المهام، موافقات وعرض جلسة العمل بصورة آمنة.
2. **Orchestrator:** تفسير الطلب، تخطيط الخطوات، إدارة الأدوات والصلاحيات والذاكرة، وإصدار تقرير نتيجة مع أدلة.
3. **Windows Cloud Worker:** جلسة تفاعلية مُدارة للتحكم بالمتصفح وبرامج Windows، مع التقاط الشاشة والتحقق من نتائج كل خطوة.
4. **Task Storage:** PostgreSQL لحالة المهام، ومعرّفات العمليات، وسجل التدقيق؛ تخزين خاص للملفات مع سياسات احتفاظ.
5. **Telephony:** مكالمات صادرة وواردة عبر مزود متوافق مع أرقام السعودية؛ التوفر والقيود والامتثال تحتاج تحققاً قبل الاختيار.
6. **Speech Runtime:** محادثة منخفضة التأخير مع إمكانية المقاطعة، وفصل صلاحيات التنفيذ عن كلام المستخدم أو محتوى المواقع.

## سياسة الصلاحيات
يُسأل المستخدم عند بداية كل مهمة عن نمطها:
- مراجعة فقط: لا تعديل.
- مراجعة وتنفيذ: داخل نطاق التفويض المحدد.
- تنفيذ بموافقة: إعداد ثم اعتماد قبل الحفظ/الإرسال.

المهام عالية الخطورة، مثل تحويل الأموال، تتطلب موافقة صريحة خاصة بالعملية، بغض النظر عن النمط.

## سياسة التحكم
- تفضيل محددات واجهات المتصفح وواجهات إمكانية الوصول، واستخدام الرؤية والإحداثيات كبديل.
- اعتبار النصوص الظاهرة على المواقع والملفات بيانات غير موثوقة، وليست أوامر.
- عدم تجاوز CAPTCHA أو المصادقة متعددة العوامل.
- لا يُعاد تنفيذ أي عملية حفظ أو إرسال إلا بعد التحقق من الحالة الفعلية لمنع التكرار.
- إيقاف طارئ، وتسجيل أسباب الفشل، وإمكانية استئناف آمن.

## قرارات تقنية لم تُحسم
- مزود Windows السحابي وترخيص التشغيل غير المراقب واستمرارية الجلسة.
- مزود مكالمات يدعم المتطلبات السعودية وربط الرقم.
- مزود نماذج الصوت والعقل المركزي وتكلفتها.
- نطاق استخدام سطح المكتب مقابل المتصفح ومراقبة جلسة العمل.

لا يوجد حالياً نشر سحابي أو تكامل فعّال؛ هذه وثيقة التصميم المعتمدة للبناء.
