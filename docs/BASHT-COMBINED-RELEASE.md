**ثم مباشرة (Squash Merge):** الدمج بـ squash ينتج commit عاديًا واحدًا بوالد واحد، لذا التراجع على `main` هو:

```
git revert <squash-commit-sha>        # بلا -m (الخيار -m 1 لا يصلح إلا لـ merge commit بوالدين)
```

الـ `<squash-commit-sha>` هو commit الدمج الظاهر على `main` لكل مستودع (المحرك والتطبيق كلٌّ على حدة؛ يُسجَّل في التقرير النهائي). يُدفع الـ revert عبر طلب دمج، ويعيد نشر الحالة السابقة تلقائيًا. بدون ذلك يعيد أول دمج لاحق نشر الكود نفسه. ثم الإصلاح في فرع جديد عبر المسار نفسه.

ملاحظة: لأن الطلبات الفرعية لم تُدمج على حدة، لا يلزم التراجع عنها؛ يكفي revert الـ squash لكل مستودع.
